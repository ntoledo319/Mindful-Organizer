# Project Hearth: Handoff Document (2026-05-29)

## 1. Project Mission & Vision
**Hearth (Mindful Organizer)** is a "psychological operating system layer." It is designed to mitigate the friction of modern computing for individuals managing ADHD, anxiety, depression, OCD, PTSD, or bipolar disorder.

The project mission is to move beyond simple "tracking" and into **active environment adaptation**. Instead of just logging a mood, Hearth reconfigures the user's desktop (UI density, notification frequency, focus modes) to meet the user's current psychological state.

### Core Principles
- **Local-First Privacy:** Zero telemetry. All health data remains on the user's local SQLite database.
- **Adaptive UI:** The interface changes based on energy levels and focus needs.
- **Action-Oriented:** Focused on the "Next Best Action" rather than an overwhelming list of chores.

## 3. Technical Architecture

### Core Modules (`src/core/`)
- **`database.py`:** The source of truth. Manages SQLite connections and migrations.
- **`task_manager.py`:** Handles task CRUD, undo/redo, and energy-based prioritization.
- **`wellness_orchestrator.py`:** The "Brain." Synthesizes data from all trackers to detect crisis signals or suggest skills.
- **`system_automation.py`:** Triggers OS-level changes (Focus Mode, notification gating).

### GUI System (`src/gui/`)
- **`main_window.py`:** The primary shell with the new side-navigation rail.
- **`themes.py`:** Controls the QSS generation. Uses "Behavioral Tokens" to change layout density, not just colors.
- **`state_bus.py`:** Handles reactive cross-widget communication.

---

## 4. Migration Logic
A critical piece of infrastructure was added to `src/main.py`:
- **Auto-Rename:** On boot, the app detects the legacy `~/.mindful_optimizer` folder. If the new `~/.mindful_organizer` does not exist, it renames the old folder. This ensures no data loss during the version jump.
- **SQLite Migration:** `main.py` triggers `MigrationManager` to pull any remaining legacy JSON records into the database.
