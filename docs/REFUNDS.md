# Hearth Purchases and Refunds

_Last updated: 2026-07-14_

Hearth is not currently listed as purchasable. If an official paid Microsoft
Store package is released, Microsoft will process the payment and any eligible
refund request under its then-current Store terms and applicable law. No direct
payment link or developer-run payment flow is active in the app.

Microsoft's refund request instructions are available at
<https://support.microsoft.com/en-us/account-billing/returning-items-you-bought-from-microsoft-for-exchange-or-refund-81629012-aa4f-f48b-2394-8596f415072b>.
