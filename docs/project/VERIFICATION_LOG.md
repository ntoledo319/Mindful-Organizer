## Dirty-tree reference format

`working-tree:<HEAD>+dirty:<fingerprint>` where the fingerprint is the first 16
hex chars of `git diff HEAD | sha256sum`, accompanied by the diff stat. A
dirty-tree pass proves that tree only — never a later commit.

be covered, hash the ordered Git status code, repository-relative path, and
working-file content for every changed path; normalize the row's own 16-hex
fingerprint to `SELF`. State that method in the row. This avoids excluding new
files or creating a self-referential hash.
