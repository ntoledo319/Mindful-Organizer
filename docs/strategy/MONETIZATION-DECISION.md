# Current Monetization Decision

_Decision date: 2026-07-14._

## Selected fast bet

Prepare an official Hearth Windows package for a one-time **$14.99** Microsoft
Store listing. The Store supplies discovery and payment. The source remains MIT;
the paid value is a maintained, packaged, Store-delivered build.

## Rejected path

The $249 clinic/fleet-key model was removed because it had no real fulfillment,
no clinical validation, no defensible license gate, and depended on autonomous
outbound that the operating doctrine forbids. The useful part—the local session
summary—now works for every user without a gate.

## Status

This is a hypothesis, not a live offer. Submission remains blocked on sensitive
data protection, asset provenance, a working support channel, a fresh Windows
package/smoke test, and manual Partner Center review. See `revenue/PLAN.md`.
