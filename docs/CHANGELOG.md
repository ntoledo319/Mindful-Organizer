# Changelog

All notable changes to Hearth are documented in this file.

## [1.1.0] — 2026-06-08

### Pricing Update

Subscription prices have been updated to reflect the significant increase in value delivered in this release.

| Tier    | Old Price                  | New Price                    |
| ------- | -------------------------- | ---------------------------- |
| Pro     | $4.99/month or $39.99/year | $8.00/month or $79.99/year   |
| Premium | $9.99/month or $79.99/year | $15.00/month or $149.99/year |

**Why the increase?**

v1.1.0 transforms Hearth from a task-manager-plus-mood-tracker into a full psychological operating system. The new features justify the updated pricing:

- **Focus Sessions / Pomodoro Widget** — Circular timer with DND integration and session history for deep work.
- **Voice Journaling** — Recorded journal entries with transcription support (when audio hardware is available).
- **Personal Insights Engine** — Real analytics generated from the user’s own data, not generic templates.
- **PDF Export** — One-click export of wellness reports and diary cards for sharing with clinicians.
- **Enhanced Auto-Updater** — In-app changelog viewer with direct download links.
- **Security Hardening** — Keyring-enforced vault encryption, hardened license validation, and HTTPS-only update channels.
- **Improved GUI Test Coverage** — More reliable UI across all supported platforms.

Existing trial users and current subscribers receive all new features automatically. The Free tier remains unchanged — crisis support, basic tasks, mood tracking, breathing exercises, and DBT diary cards are still free forever.

This pricing aligns Hearth with the value it delivers: OS-level automation infrastructure that no pure wellness app or productivity tool offers on its own.

### Added

- Focus Sessions widget with circular Pomodoro timer and DND integration.
- Voice journaling module with recording capability.
- Personal Insights engine for user-data-driven analytics.
- PDF export for reports and diary cards.
- Hardened auto-updater with changelog and download links.

- License validation hardening.
- HTTPS-only update channels.

### Fixed
