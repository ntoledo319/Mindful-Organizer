# Hearth Support

_Last updated: 2026-07-14_

## Current availability

Hearth is not currently released. The intended public support channel is the
repository's
[GitHub Issues](https://github.com/ntoledo319/Mindful-Organizer/issues/new/choose),
but new-issue creation must be enabled and verified before this link is entered
in a Store listing or described as available customer support.

## What a useful report contains

After the channel is verified, include:

- Hearth version
- Windows version and x64 device confirmation
- The action immediately before the problem
- What was expected and what happened
- Whether it repeats after a normal app restart
- A screenshot only if it contains no private record

Never attach or paste:

- hearth.secure, hearth.secure.backup, hearth.secure.migration-backup, or
  hearth.key
- legacy hearth.db, hearth.db-wal, hearth.db-shm, or journal files
- JSON or PDF exports, because Hearth exports are readable plaintext files
- journal, crisis-plan, ERP, diary-card, medication, mood, anxiety, or sleep
  content
- Windows account details, payment details, tax details, credentials, or keys

## Boundaries

GitHub Issues is a public software-support channel. It is not private, clinical,
medical, crisis, or emergency support. In a US crisis, call or text 988; in
immediate danger, call the local emergency number.

Purchases and eligible refunds are handled through Microsoft under
[the refund policy](REFUNDS.md).
