# Capability and Asset Vault

This directory preserves material removed from the shipping experience so
release hardening never destroys prior work. Vaulted files are reference-only:
they are not packaged, published, or represented as rights-cleared.

`unverified-2026-07-14/` contains the previous app icon and onboarding hero,
retained byte-for-byte while deterministic, repository-owned replacements ship.
